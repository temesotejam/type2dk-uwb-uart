# Type2DK Programmer GUI 1.0.0

任意のBINを選び、今使っているDK6Programmerで書き込み・読み出し照合を行うWindows用アプリです。
19番・21番・22番の専用メニューはなく、書き込むBINを毎回自分で選びます。

## 使い方

1. ZIPを右クリックして「すべて展開」します。
2. `Type2DK-Programmer.exe`をダブルクリックします。
3. 「DK6Programmer」の「参照」で、**今コマンドで使えているフォルダ内のDK6Programmer.exe**を選びます。
4. 基板をUSB接続し、「COM一覧を更新」→接続先を選びます。基板名の19・21・22とCOM番号は別です。
5. 「BINを選ぶ」で、接続した基板用の任意の`.bin`を選びます。
6. シリアルモニターを閉じて「書き込み・照合」を押します。
7. **「完了：書き込み・読み出し照合に成功しました。」**が出るまで待ちます。

通常は1000000 bpsを使用します。接続が不安定なら115200 bpsへ下げられます。
この速度は書き込み時専用です。アプリ動作時のUARTやUSBログの速度は変更しません。
基板の書き込みモードへの入り方、USBドライバや配線は従来と同じです。
ログは画面内に表示し、必要なら「ログを保存」でテキスト保存できます。

## 必要なもの

- Windows 10/11、.NET Framework 4.8以降。Pythonや開発環境は不要です。
- 既存のDK6ProductionFlashProgrammer一式。
- 接続するType2DK用のBIN。

アップロードされたBuild 2282のフォルダには以下のファイルがあります。
**DLLを個別に移動せず、このフォルダをそのまま使ってください。**

| ファイル | 内容 |
|---|---|
| `DK6Programmer.exe` | 書き込みツール |
| `programmer.dll` | 書き込み処理 |
| `pdcurses.dll` | コンソール関連の依存DLL |
| `ftd2xx.dll` | FTDI通信関連のDLL |
| `libgcc_s_dw2-1.dll` | 実行時ライブラリ |

GUIのZIPにはNXP/FTDIのプログラムやDLL、BINは含めていません。
PCにある既存のフォルダを指定するので、これらの再インストールは不要です。
既定の`C:\NXP\DK6ProductionFlashProgrammer\DK6Programmer.exe`は自動検出します。
選んだプログラマの場所・COM・速度を次回も使います。BIN自体は毎回選び直します。

## 処理と結果表示

GUIはシェルを通さずDK6Programmerを起動し、FLASHにだけ書き込みます。
選択したBINを一時フォルダへコピーし、そのコピーのSHA256をログに記録します。
元のBINが後から変更されても、書き込み中の内容は変わりません。

内部の指定は`-V 0 -P <速度> -s <COM> -Y -v -p FLASH=<一時BIN>`です。
通常の部分消去・アプリの書き込み・読み出し照合を行います。全消去やOTP書き込みは実行しません。
GUIはBINの役割やハードウェア適合性を判断しないため、接続したType2DKに合うBINを選んでください。

終了コード0、`Memory programmed successfully`、`Memory verified successfully`の
**3条件がすべてそろったときだけ成功を表示します。** アプリとしての起動・測距成功は別の動作確認です。

書き込み中の二重実行とウィンドウを閉じる操作は防ぎます。
処理が戻らない場合の「強制停止」は確認後に実行し、成功とは表示しません。
中断した場合は、従来の手順で書き込みモードへ戻して再度書き込んでください。

## 検証範囲

Windows CIでビルド、GUIの起動・画面描画、模擬プロセスによる書き込み結果判定を確認します。
検証には成功、照合メッセージ欠落、終了コード異常、両出力への大量ログ、強制停止、
パスの空白・日本語・引用符の受け渡し、一時BINの固定・削除、DLL不足の検出を含みます。
**CIは実機やNXPのEXEを実行する試験ではありません。最初の実機書き込み結果を確認してください。**
GUIは新規作成のため署名は付いていません。

## 再ビルド

Windowsの.NET Framework C#コンパイラでビルドします。

```powershell
.\tools\dk6-gui\build.ps1
```

`out/type2dk-programmer-gui-v1.0.0.zip`が配布物です。
`tests/`の模擬プログラマは配布ZIPには入りません。
