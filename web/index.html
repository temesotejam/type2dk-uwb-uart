03 / 成功したUART配線のまま接続

電源を切って接続します。19番だけをCoreS3につなぎます。

19番Type2DK・TP8CoreS3 PORT A
2番：PIO13 / SWDIO黄：GPIO2 / RX
3・5・9番のいずれか：GND黒：GND
PIO12接続不要
接続しない白GPIO1・赤5V

外付けプルアップは不要です。4組の電源ジャンパはそのまま、各基板をUSB給電してください。

04 / 距離と受信を一緒に確認

  1. 19番と21番を起動します。22番は最初は電源を切っておきます。
  2. UWB初期化後にRECEIVINGとなり、19–21の距離とupdatesが更新されるか確認します。
  3. 21番を少し動かし、距離表示が追従するか確認します。CLEARを押して60秒観測します。
  4. 22番も起動し、19–22も更新されるか確認します。

受信は約5回/秒が目安です。BAD・MISS・F_ERR・OVFが増えず、接続相手のupdatesが増え続けるかを見ます。

UART診断版から、2DKのUSBログ速度が変わります。
CoreS3：115200 bps ／ 2DK：3000000 bps

CoreS3のRANGE_STAT・RANGE_DATAを10秒分共有してください。測距が始まらない場合は19番の起動からのログも必要です。
