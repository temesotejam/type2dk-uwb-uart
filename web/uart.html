最初に：信号線を外して両方を更新

電源を切り、CoreS3と2DKの間のSDA・SCL線をいったん外してください。I2C用に追加した2本のプルアップ抵抗と電源線も外します。基板の4組の電源ジャンパはそのままです。

CoreS3と2DKの両方をこのUART版へ更新してから接続します。

01 / CoreS3受信版を書き込む

PCのChromeまたはEdgeで開き、CoreS3をUSB接続します。

PC版Chrome／Edgeを使ってください。HTTPSで開いてください。

ファームウェアを確認しています…

完了後、画面の 1.2.0-uart を確認します。画面が出なければRESETを短く押してください。

現在のアプリを書き換えます。Erase deviceを選ぶと保存データも消えます。

02 / 2DK送信版を書き込む

2DK UART送信版 v1 BIN

2DKのシリアルモニターを閉じ、DK6Programmerで書き込みます。

.\DK6Programmer.exe -V 0 -P 1000000 -s COM19 -Y -v -p .\2dk_uart_tx_v1.bin

COM19はこれまで使っていた番号です。必要なら現在の番号に変更してください。書き込みと照合の完了を確認します。このページのCoreS3用ボタンでは2DKを書き込めません。

03 / 電源を切って2本だけ接続

Type2DK Rev.4.1・TP8CoreS3 PORT A
2番：PIO13 / SWDIO（送信）黄：GPIO2（受信）
3・5・9番のいずれか：GND黒：GND
4番：PIO12 / SWCLK白：GPIO1 — 接続不要
接続しない赤：5 V — 接続不要

両方をそれぞれUSB給電します。外付け抵抗とTP18への追加配線は不要です。実物の1番表示を確認し、SWD書き込み器を外してください。

同じ線へI2Cセンサを接続しないでください。古いI2C版のCoreS3とも組み合わせないでください。

04 / 30秒間の受信を確認

2DK起動から約2秒後に送信開始。CoreS3は自動受信します。RECEIVINGになったらCLEARを押します。

表示期待値
OK / RATE毎秒およそ50増加 / およそ50/s
BAD / MISS / DUP0 / 0 / 0
FRAME_ERR / OVERFLOW0 / 0

WAITING：正常受信待ち。NO DATA：最後の正常受信から500 ms超。RESET：2DKの再起動検出数です。

CoreS3のUSBシリアルを115200 bpsで開き、UART_STATを5～10行共有してください。2DKのUSBログも115200 bpsです。基板間の38400 bpsとは別です。

2DKのSW1を押すとBOOT,2DK_UART_TX_V1を表示し、UART_TXを毎秒出します。
